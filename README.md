# lucky-roger-slot
Retro 5-reel pirate-themed slot machine web app inspired by the classic "Lucky Roger" arcade cabinet. Built with vanilla HTML/CSS/JavaScript featuring lines selection, risk card game, and an interactive bonus stage with treasure chests! 🏴‍☠️🪙

# 🏴‍☠️ Lucky Roger Slot

Вестальгический веб-клон культового олдскульного игрового автомата **«Lucky Roger»** («Веселый Роджер»), стилизованный под наземные аркады 2000-х. 

Приложение написано на чистом **HTML, CSS и JavaScript**, работает прямо в браузере без установки дополнительных библиотек и зависимостей.

---

### 🕹️ Особенности игры:
* **Классическая механика:** 5 барабанов, выбор линий (от 1 до 9) и гибкая настройка ставки на линию.
* **Пиратская символика:** Веселый Роджер (Wild), Бомбы (Bonus), Сабли, Золотые монеты, Ром, Попугаи и Компасы.
* **Интерактивный бонусный раунд:** При выпадении 3+ бомб запускается игра с поиском сокровищ в пиратских сундуках (но берегись ловушек!).
* **Риск-игра (Удвоение):** Классическая карточная игра с дилером на удвоение каждого выигрыша.
* **Оптимизация:** Работает как на ПК, так и на мобильных устройствах благодаря адаптивной верстке.
